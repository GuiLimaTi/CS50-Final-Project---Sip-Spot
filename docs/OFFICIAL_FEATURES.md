# Official Features - Sip Spot

## Project Title
Sip Spot

## Core Idea
Sip Spot is a web application designed to help users find coffee shops in the Temple Bar area of Dublin based on practical and relevant information.

The goal of the project is to make coffee shop decisions easier. Instead of choosing a café at random, users can compare places according to what matters most to them, such as coffee type, price, seating, work-friendliness, Irish coffee availability, rating, and opening or closing time.

Sip Spot is focused on useful local information and a simple decision-making experience.

---

## Main Functional Features

### 1. Coffee Shop Listing
The application displays a list of coffee shops located in the Temple Bar area.

Each listing helps users quickly compare available options and decide which place may suit their needs best.

---

### 2. Coffee Shop Details
Each coffee shop has its own detailed information page.

The details available for each shop include:

- name
- address
- coffee types available
- price by coffee type
- rating
- sit-in or takeaway availability
- work-friendly suitability
- Irish coffee availability
- opening time
- closing time
- notes or short description

This feature gives users a fuller understanding of each place before visiting it.

---

### 3. Filter by Coffee Type
Users can filter coffee shops by coffee type.

Example values include:

- Americano
- Espresso
- Cappuccino
- Latte
- Flat White
- Irish Coffee

This allows users to search according to the kind of coffee they actually want.

---

### 4. Filter by Maximum Price
Users can define a maximum price for the selected coffee type.

This feature helps users compare cafés based on budget and practical value.

It allows the application to answer questions such as:
- Where can I get an Americano under a certain price?
- Which places fit my budget better?

---

### 5. Filter by Work-Friendly Option
Users can filter coffee shops according to whether the place is suitable for working or studying.

Possible values include:

- Yes
- No
- Limited

This is useful for users who need seating, a calm atmosphere, or a place to stay longer.

---

### 6. Show Sit-In or Takeaway Information
The application clearly displays whether a coffee shop:

- offers sit-in service
- is takeaway only
- offers both sit-in and takeaway

This feature helps users choose according to how they want to use the space.

---

### 7. Show Irish Coffee Availability
The application shows whether a coffee shop serves Irish coffee.

This is especially useful for tourists or users who want a more local and traditional coffee experience in Dublin.

---

### 8. Show Opening Time
The application displays the opening time of each coffee shop.

This helps users identify places that open early enough for breakfast or morning coffee.

---

### 9. Show Closing Time
The application displays the closing time of each coffee shop.

This is an important practical feature because many coffee shops in Dublin close earlier than visitors might expect.

It helps users avoid wasting time by going to a place that is already closed.

---

### 10. Show Rating
Each coffee shop includes a rating value.

This rating is intended to represent the public score used in the project, such as a Google rating.

Example values include:

- 4.7
- 4.3
- 3.9

This allows users to compare coffee shops not only by price, but also by overall evaluation.

---

## Data Stored for Each Coffee Shop
Each coffee shop entry in Sip Spot should store:

- coffee shop name
- address
- one or more coffee types
- price for each available coffee type
- rating
- work-friendly category
- sit-in / takeaway category
- Irish coffee availability
- opening time
- closing time
- notes
- image filename for visual display

This data supports both the filter system and the details page.

---

## Main User Actions
The user can:

- view coffee shops included in the app
- apply filters to narrow the list
- compare coffee shops using practical criteria
- open a coffee shop details page
- review prices and categories
- decide which place best matches their needs

These actions define the core experience of Sip Spot.

---

## Key User Questions the App Answers
Sip Spot is designed to answer practical questions such as:

- Where can I get an Americano under a certain price?
- Which coffee shops are good for working?
- Which places have sit-in availability?
- Which coffee shops serve Irish coffee?
- Which coffee shops open earlier?
- Which coffee shops close later?
- Where can I find a good coffee in Temple Bar?

These questions reflect the real use case of the application.

## Features Summary
Sip Spot focuses on practical, local, and user-friendly features that help people make better coffee shop decisions in Temple Bar.

Its main strengths are:

- useful local focus
- practical filtering
- simple comparison between coffee shops
- clear details pages
- a realistic Version 1 scope

The project is intentionally focused on a manageable set of features that solve a real everyday problem while still allowing room for future growth.
