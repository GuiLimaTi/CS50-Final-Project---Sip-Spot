# Official Scope - Sip Spot

## Project Title
Sip Spot

## Project Type
Web application

## Project Overview
Sip Spot is a web application designed to help users find suitable coffee shops in the Temple Bar area of Dublin.

The project focuses on practical information that can improve a user’s decision before visiting a coffee shop, such as coffee type, price, seating availability, work-friendliness, Irish coffee availability, rating, and opening and closing times.

The main purpose of the project is to solve a simple but real problem: many people visit Temple Bar and want to stop for a coffee, but they do not know which place best matches their needs. Some users want a cheaper coffee, some want a place to sit down and relax, some want a place that is good for working, and some want to find a café that is already open or still open later in the day.

Sip Spot is designed to make that choice easier, clearer, and more practical.

---

## Target Users
Sip Spot is designed for:

- tourists visiting Temple Bar
- people exploring Dublin city centre
- coffee lovers looking for useful local information
- users who want more than just a list of cafés
- people who want to compare coffee shops based on practical needs

These users may have different priorities, but they all benefit from having clear and structured information before choosing a coffee shop.

---

## Main Problem the Project Solves
Sip Spot helps users choose the right coffee shop in Temple Bar based on practical and relevant criteria.

Instead of entering a café without knowing what to expect, users can check useful details in advance, such as:

- whether the rating is strong
- whether the place is cheaper or more expensive
- whether customers can sit down
- whether the coffee shop is suitable for working
- whether Irish coffee is available
- what time the shop opens
- what time it closes

This turns a random decision into a more informed and useful one.

---

## Scope of Version 1
The first version of Sip Spot focuses only on coffee shops located in the Temple Bar area.

This is a deliberate design decision to keep the project:

- realistic
- focused
- manageable
- strong enough for the CS50 final project

Version 1 includes the following core features:

### 1. Coffee Shop Listings
Users can view a list of coffee shops included in the application.

### 2. Coffee Shop Details
Each coffee shop has its own detailed information page, including:

- coffee shop name
- address
- rating
- coffee types available
- price by coffee type
- sit-in or takeaway information
- work-friendly information
- Irish coffee availability
- opening time
- closing time
- notes

### 3. Filtering Features
Users can filter coffee shops by:

- coffee type
- maximum price
- work-friendly suitability
- sit-in or takeaway availability
- Irish coffee availability
- opening time
- closing time

### 4. Practical Search Experience
The application helps users answer practical questions such as:

- Where can I get an Americano under a certain price?
- Which coffee shops are good for working?
- Which places allow customers to sit down?
- Which cafés serve Irish coffee?
- Which coffee shops open earlier?
- Which coffee shops close later?

---

## What Is Included in Version 1
The official scope of Version 1 includes:

- a web-based interface
- a list of coffee shops in Temple Bar
- coffee shop cards or listings
- a results section integrated into the Home Page
- detailed information pages for each coffee shop
- filter options for practical decision-making
- a simple and user-friendly design
- a focused dataset limited to Temple Bar
- project branding and logo
- coffee shop images
- an About page explaining the project

These features define the complete Version 1 experience.

---

## What Is Not Included in Version 1
To keep the project realistic and achievable, the following features are outside the scope of Version 1:

- mobile app development
- real-time GPS navigation
- automatic map routing
- support for all areas of Dublin
- live business data from external APIs
- user accounts and authentication
- public user reviews or ratings submitted by visitors
- advanced recommendation algorithms
- favourites system
- map page with live interaction

These ideas may be valuable later, but they are not necessary for the first version.

---

## Design Priorities
The main design priorities of Sip Spot are:

- simplicity
- clarity
- practical usefulness
- strong local focus
- responsive web design
- easy comparison between coffee shops

The interface should help users understand the app quickly and make decisions without confusion.

---

## Reason for the Narrow Scope
Temple Bar was chosen as the starting area because:

- it is one of the most famous parts of Dublin
- it attracts many tourists and visitors
- it is busy and highly relevant for this type of app
- it keeps the project small enough to remain realistic
- it reflects the creator’s own experience working in a coffee shop in central Temple Bar

This narrow focus makes the project more personal, more realistic, and easier to manage well.

---

## Future Expansion Possibilities
Although Version 1 is limited to Temple Bar, the project could be expanded in the future to include:

- more areas of Dublin
- more coffee shops
- favourites
- rankings
- user accounts
- user-submitted reviews
- map integration
- improved search and sorting
- a mobile app version

These ideas are possible future developments, but they are intentionally excluded from Version 1.

---

## Scope Summary
Sip Spot is a focused coffee finder web application for Temple Bar.

Its first version is designed to help users choose coffee shops based on practical information such as coffee type, price, seating availability, work-friendliness, Irish coffee availability, rating, and opening and closing times.

The scope is intentionally narrow so the project remains manageable, useful, and strong as a CS50 final project. At the same time, the idea has clear room for future expansion.
